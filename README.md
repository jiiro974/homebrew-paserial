# Jiiro974 Paserial

## How do I install these formulae?

`brew install jiiro974/paserial/<formula>`

Or `brew tap jiiro974/paserial` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jiiro974/paserial"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
